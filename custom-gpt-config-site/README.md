# AI UX Heuristic Auditor — Custom GPT Configuration

A static documentation page for the Custom GPT setup used in an AI UX heuristic audit experiment.

## View locally

Open `index.html` in a browser. The page uses relative asset paths and does not require a build step or external libraries.

## Publish with GitHub Pages

1. Add the contents of this folder to a GitHub repository (or a folder in an existing repository).
2. Ensure `index.html`, `instructions.md`, and the `assets/` folder are committed together.
3. In the repository settings, enable GitHub Pages for the branch and folder containing these files.
4. Open the published Pages URL and test it on desktop and mobile.

## What is documented

- GPT name and description
- Recommended model setting
- Capabilities and additional settings visible in the screenshots
- Visible instruction text
- Knowledge file names
- Conversation starters visible in the screenshot
- Configuration screenshot evidence

## Accuracy notes

This is a documentation page, not an importable GPT export. The screenshot's Recommended Model field says "No Recommended Model". The preview pane also displays a model label; that does not establish which model was used for a particular audit. Record the actual model from the audit run separately.

The three original knowledge files are not included in this package because only their names were visible in the screenshot. Add the original files if you intend to redistribute them.
